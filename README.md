# DMOJ Solutions

A collection of solutions to problems from the **DMOJ Online Judge**, written in various languages.  
Each solution is self‑contained and designed to run efficiently under judge constraints.

---

## Structure

DMOJ/
├── Rust/src/bin/\<problem slug\>.rs   # Rust solutions
├── \<other language\>/     # Replace <other language> with name of programming language solution
|
└── README.md

---

## Running Solutions

### Rust

cargo build --release
./target/release/\<problem slug\> < input.txt

---

## Notes

- All solutions follow judge‑friendly input/output formats.  
- Code is kept minimal and focused on correctness.
